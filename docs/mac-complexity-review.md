# `farrow mac` 复杂度专项治理

日期：2026-09-28。范围：当前未发布的 Mac 实现，包括命令入口、Go 管理层、原生 runner、网络 helper，以及构建交付代码。本次直接修改源码，保持现有命令、状态格式、目录布局和实例身份兼容。

## 结论

值得优先消除的是重复的入口处理、重复的状态判断、重复的 SSH 材料读取，以及已经有取消机制却又另起 goroutine 的等待方式。本次生产代码净减少 **180 行**；两个命令入口文件从 **555 行减到 449 行，减少 19.1%**。没有增加依赖。

代码行数按本次修改前的工作区快照比较，包含空行与注释，不包含测试和文档。没有为了缩减数字删除回归测试或合并多行语句。

## 同时修复的实际问题

1. **健康实例被 doctor 误报。** `inspectRuntime` 在 SSH/sudo 成功后将展示状态设置为 `ready`，原来的 doctor 只接受 `running/stopped/created`。新增回归用例先复现了 `ready-ready` 失败，再修正判断；现在会输出成功的实例 SSH 检查。
2. **已初始化实例检查时仍然写 SSH 文件。** 原来在校验已有私钥后继续调用 `ensureSSHKey`，每次重写 `.pub`，并存在校验和创建分离的间隙。现在已初始化实例只读取原始私钥及主机密钥记录；缺失材料仍给出恢复提示，不创建替代密钥。

## 审查后保留的复杂度

这些部分有明确的现有用途，直接删掉会改变功能或恢复能力：

- **Go 管理层、Swift 虚拟机进程、root 网络 helper 的分工。** 三者分别负责持久状态与 CLI、Apple 虚拟化与桌面、特权网络。将它们合并会扩大特权进程或把平台实现引入普通 Go 主程序。
- **共享状态锁、实例操作锁、原生 runner 生命周期锁。** 它们保护不同对象：镜像引用和清理、同实例操作、真实 VM 进程。独立实例锁使长时间准备镜像不阻塞另一台 VM 关机；RPC 不响应时仍需 runner 锁确认停止。
- **SSH 首次信任验证与后续主机密钥固定。** helper 的连接来源验证解决首次连接的身份边界，`known_hosts` 解决之后的身份校验，两者并不重复。
- **Keychain 签名所有者保留与可恢复迁移。** 这部分代码较重，但已有开发签名更换的实机需求，并且已有实例使用它。删除备份或回滚会使迁移中断后失去正常读取密码的路径。正式签名稳定后，可以依据真实升级支持范围再评估退役开发期兼容分支。
- **IPSW 断点续传、完整性验证、基础镜像不可变与孤立文件保护。** 安装包约 26.63 GB，下载中断和安装失败是实际场景；这些机制有直接的重试成本与数据保护收益。
- **两种原生错误形状。** Swift runner 当前返回对象错误，网络 helper 当前返回字符串错误。`Runner.Call` 对两者的解析是当前协议需求，不是无人使用的旧格式兼容。

本次不引入通用 VM 后端接口、命令描述 DSL、通用事务框架或新的持久化状态机。两个固定实例继续使用直接的生命周期代码。也不为追求文件数量更少，把 Mac 与 Linux 的状态和生命周期合并。
